# humanizer

Remove AI writing patterns from Chinese and English text so it reads like a
human wrote it. Detects and fixes: AI-frequent vocabulary, over-structuring,
false objectivity, mechanical connectors, perfectionism traps, formulaic
endings, over-decoration, missing emotion, "not X but Y" strawmen with
synonym swaps, and inexplicable metaphors.

Includes `references/` with banned-word lists, structure anti-patterns and
worked before/after examples.

Ships as an agent SKILL.md: install by copying the folder into your agent's
skills directory.
